# Western geography atlas

Created November 4, 2026 with the built-in image generation tool. Published as
`docs/world-map.png`; README embeds and opens that permanent asset.

Reference: the previous painterly atlas from commit `6d6502a`, before the rough
composite. The generated original remains in the tool's generated-images folder.

This revision moves the quarry, swamp and Sunken Coast to Stillbury's bank;
expands the western desert, red mountains and snowy terrain; and depicts the
confirmed western passage through Sunscar, Giant's Peaks and Giant's Bridge.
Roads to the relocated future regions remain deferred. Northern geography is
provisional context for later acts.

The playable Peaks form a five-stage pass: Sunscar enters from the south,
Stillbury's bridge road enters from the north. The bridge itself is freely
crossable; the Jarl blocks onward departure from the Peaks until defeated.
There is no exterior shortcut around the five stages.
