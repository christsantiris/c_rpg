# Glassdeep Caverns — replaced by Stonewake Quarry

Glassdeep has been replaced in place by [Stonewake Quarry](stonewake-quarry.md),
south of Stillbury. This link remains for older documentation and save references.
Existing `glassdeep_*` save keys, location IDs, quest progress and boss victories
migrate without discarding the player's progress. See the Stonewake guide for
current stages, machinery, enemies, quest rewards and save-version 194 behavior.
