# The Silent Stormbell — native renderer review

Reviewed on 2026-10-27 at the game's native 24-pixel tile scale.

The bronze clapper and weathered timber bell frame are generated by
[stormbell.py](../../../tools/sprites/stormbell.py) through the established
[pixelkit.py](../../../tools/sprites/pixelkit.py) pipeline. The transparent
72 × 40 atlas contains a broken bell, repaired bell, and loose clapper;
the renderer draws each 24 × 40 frame without resizing. Transparent pixels
preserve the terrain underneath. Watchkeeper Seren uses the established
[native NPC renderer](../../../src/renderer/npc_renderer.c), with a blue
watchkeeper's coat and a small bronze bell accessory.

The captures below come from the actual SDL game renderer through
[test_stormbell_renderer](../../../tools/tests/debug_shortcuts_test.c).
They were inspected beside the player, existing enemies, and Dawnmere's
existing merchant building at the same rendering scale.

Reproduce the runtime art with `.venv/bin/python tools/sprites/stormbell.py`.
Build and run `debug_shortcuts_test` to regenerate the SDL captures under
`/tmp/stormbell-*.bmp`. The test harness runs in an isolated temporary directory.
