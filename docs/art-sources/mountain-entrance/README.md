# Goblin Mountains entrance

Generated by `python3 tools/sprites/mountain.py` with the established pixelkit
pipeline. Runtime asset: `assets/images/mountain-entrance.bmp` (168×144 RGBA).
Seven tiles wide, six high, with the south-facing cave door centered on the
approach entrance tile. No snow: the northern cold regions remain distinct.

The rocky peaks use shaded polygon facets, ledges and scree. Masonry, timber,
iron spikes and red goblin banners reinforce the cave mouth. Doorway proportions,
outline weight and light direction match the established building sprites.

`scale-comparison.png` shows the mountain beside the crypt at the same native
scale (enlarged 3× with nearest-neighbor sampling). `renderer-preview.png` uses
the actual SDL game renderer with town grass, cobblestones and the new road.
The mountain landmark occupies the same coordinates when approached from either
town; both directions start the interior climb at level 1.
