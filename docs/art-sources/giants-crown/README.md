# Giant's Peaks art

- `entrance.png`: native 168 × 144 entrance, generated by `tools/sprites/giants_crown.py` using pixelkit.
- `native-scale-review.png`: the entrance beside Ashen Hollow and the established blacksmith at their original pixel sizes.
- `approach.png`, `stage-1.png` through `stage-5.png`, and `castle-road.png`: captures from the actual SDL software renderer, without resizing.
- Runtime entrance: `assets/images/giants-crown-entrance.bmp`.
- Runtime atlas: `docs/images/world-map-giants-peaks.png`.

Ogre and Hill Giant retain the original 24-pixel giant silhouette, with separate
skin palettes. The Last Jarl adds a crown. Existing Stone Giant, Frost Giant,
Cave Troll, and Stone Troll artwork keeps its established rendering dimensions.

The atlas was edited with the built-in imagegen tool. The final prompt is in
[`atlas-prompt.md`](atlas-prompt.md). Both source atlases remain available:
`docs/images/world-map-ironfang.png` and the revised Giant's Peaks atlas.
