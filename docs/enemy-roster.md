# Enemy names and areas

This is the current spawn roster, including quest encounters and summoned
enemies. It covers all **102 defined enemy types**, all of which have current
spawns. The 22 named variants are listed separately because they reuse these
types. Removed enemy IDs remain reserved in the save format; they are no longer
runtime enemy definitions. The six retired Pirate Coast IDs also remain unused.

Names follow the game display, including Rockworm/Quarry Construct/Stone Troll
in place of the old Glassdeep creatures. The Dungeon is on the Oakhaven–Dawnmere
route. Rook's Labyrinth is its own area beside the Haunted Forest road entrance.
Castle entries below refer to the castle interior, not Castle Grounds.

## Save compatibility

Save version **196** removes six unused definitions and their combat/rendering
paths. All surviving type IDs keep their existing numeric values. On load, old
serialized actor IDs 1, 3 and 4 become Goblin Scout, Hobgoblin Guard and Cave
Troll. Retired dungeon boss IDs 6, 8 and 10 become the current Lich King.
Names update while health, death state, statistics, positions and timers remain
intact in active and cached floors. Legacy finales retain their geometry and
dropped loot rather than regenerating the floor. Subsequent saves contain only
supported enemy IDs.
